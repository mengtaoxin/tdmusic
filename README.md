# tdmusic

Vue 3 SPA with Vite, TypeScript 6, Vitest, Playwright, and Vuetify (Material Design).

## Stack

- Vue 3 + Vue Router (SPA)
- Vite
- TypeScript 6.x
- Vuetify 4 (Material Design) + MDI icons + Roboto
- Vitest (unit) + Playwright (e2e)

## Setup

```sh
npm install
```

### Development

```sh
npm run dev
```

### Production build

```sh
npm run build
```

### Unit tests

```sh
npm run test:unit
```

### End-to-end tests

```sh
npx playwright install
npm run test:e2e
```

### Lint & format

```sh
npm run lint
npm run format
```
